# JustWrite <img src="JustWrite Images/icon.png" width="28">

"Write as if no one will ever read this..."

![JustWrite](JustWrite%20Images/img%20(5).png)

JustWrite is a minimal, immersive, and distraction-free writing environment built with Python and `customtkinter`. It is designed to remove the complexity of traditional word processors and help you focus purely on the flow of your thoughts.

Whether you're drafting a novel, scribbling ideas, or diving into poetry, JustWrite provides a beautiful, focused space for your creativity.

## Features

JustWrite is packed with unique features designed for the focused writer:

| Feature | Icon | Description |
| --- | --- | --- |
| **Full Screen Mode** | <kbd>ESC</kbd> | Launches the app into true full-screen mode to eliminate all desktop distractions. |
| **Thematic Writing** | <kbd>Theme</kbd> | Cycle through **unique, pre-built themes** that instantly change the entire application's color scheme, including background, text, and accent colors. |
| **Elysium Mode Timer** | <kbd>Timer/Reset</kbd> | A built-in **15-minute countdown timer** to encourage focused, sprint-like writing sessions. Toggle to start/pause, or reset instantly. |
| **Poetry Mode** | <kbd>Poem</kbd> | Toggles a special layout with a **narrower text area** and **increased line spacing** (leading) perfect for drafting poems and short-form verse. |
| **Dynamic Typography** | <kbd>Font/Size</kbd> | Cycle through **different font families** and **different font sizes** on the fly, allowing you to instantly change the feel of your workspace. |
| **Integrated I/O** | <kbd>Save/Load</kbd> | **Save and Load** your work into a custom `.jstwrt` JSON file, which intelligently preserves your **text content, current theme, font, and size settings**. |
| **PDF Export** | <kbd>PDF</kbd> | **Export your current document as a PDF file**, complete with the background and text colors of your currently active theme for a stunning and consistent look. |
| **Floating Sidebar** | <kbd>☰</kbd> | The customizable settings sidebar can be **toggled on or off** to maximize your writing space, giving you complete control over the interface. |

## Installation & Setup
